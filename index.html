개요 및 사용 목적

예시: BRCA1_250924_7500443_M1_SP6-R.ab1

이 도구는 Product(M1, M2…)와 Primer(T7-F, SP6-R…) 조합을 보고, 해당되는 엑손 접두어를 자동으로 삽입합니다.

변환 후

1
파일명 구조 이해하기
각 파트가 무엇을 의미하는지 알아봅니다

AB1 파일명은 _(언더바)로 구분된 여러 파트로 구성됩니다. BRCA1을 예시로 살펴봅니다.

BRCA1_ 250924_ 7500443_ M1_ SP6-R .ab1
① ITEM (유전자명) ② 접수 날짜 ③ 샘플 번호 ④ Product (앰플리콘) ⑤ Primer
파트설명예시
① ITEM분석하는 유전자 또는 검사 항목명. 파일명의 첫 번째 _ 앞 부분.BRCA1, NOTCH3
② 날짜시퀀싱 접수 날짜 (YYMMDD 형식)250924 = 2025년 9월 24일
③ 샘플번호환자 또는 샘플 식별 번호7500443
④ ProductPCR 앰플리콘 번호. 어떤 구간을 증폭했는지를 나타냄.M1, M2, M3…
⑤ Primer시퀀싱에 사용한 프라이머명SP6-R, T7-F
⚠
Product 위치는 ITEM마다 다를 수 있습니다. BRCA1은 4번째 파트가 Product(M1)이지만, 다른 유전자는 위치가 다를 수 있으므로 규칙 설정 시 확인이 필요합니다.

변환 결과: Product와 Primer 조합에 따라 해당되는 엑손 접두어가 Product 앞에 삽입됩니다.

변환 전: BRCA1_250924_7500443_M1_SP6-R.ab1
변환 후: BRCA1_250924_7500443_ex1_M1_SP6-R.ab1
↑ M1 + SP6-R → ex1 (BRCA1 규칙 테이블에서 조회)
2
ITEM 규칙 설정하기 처음 한 번만
유전자별 Product × Primer → Prefix 매핑 테이블을 등록합니다
💡
규칙을 한 번 설정하면 브라우저에 자동 저장됩니다. 같은 컴퓨터에서 다시 열어도 규칙이 그대로 남아 있습니다. (브라우저 캐시 삭제 시 초기화)

ITEM 규칙이란?
특정 유전자(ITEM)에 대해, 어떤 조합이 어떤 접두어(ex1, ex2…)에 해당하는지를 정의한 표입니다. 유전자 유형에 따라 두 가지 모드 중 하나를 선택합니다.

일반 모드 (기본)

Product + Primer 조합 → Prefix
BRCA1, NOTCH3처럼 M1, M2… Product가 있는 유전자에 사용

Primer 단독 모드

Primer만 → Prefix
LHON처럼 Product 없이 Primer만 파일명에 있는 유전자에 사용

예: BRCA1 규칙 테이블의 일부
Product | Primer | Prefix(접두어)
─────────────────────────────
M1 | SP6-R | ex1
M1 | T7-F | ex1
M2 | SP6-R | ex2
M2 | T7-F | ex2

규칙 추가 방법 (단계별)

1
화면 상단 "ITEM 변환 규칙 관리" 패널을 펼칩니다
페이지 상단에 접혀 있는 패널을 클릭하면 현재 등록된 규칙 목록이 보입니다. BRCA1은 기본으로 등록되어 있습니다.
2
"+ ITEM 규칙 추가" 버튼을 클릭합니다
설정 창이 열립니다. 기존 규칙을 수정할 때는 해당 행의 ✏ 수정 버튼을 클릭하세요.
3
ITEM 이름을 입력합니다
파일명 첫 번째 _ 앞 부분과 정확히 동일하게 입력합니다.
예: 파일명이 NOTCH3_260507_...이면 → NOTCH3 입력
대소문자를 구분하지 않으며, 저장 시 자동으로 대문자로 변환됩니다.
4
Product 위치를 확인합니다
파일명을 _로 분리했을 때 Product(M1, M2…)가 몇 번째에 있는지 입력합니다.
예: NOTCH3(1)_260507(2)_7370170(3)_M1(4)_T7-F(5) → 4번째 → 4 입력
창 하단 미리보기에서 위치가 맞는지 확인하세요.
5
매핑 테이블에 Product × Primer → Prefix를 입력합니다
방법 A — Excel에서 가져오기: 기존 접수 파일이 있으면 "↑ Excel에서 가져오기" 버튼으로 자동 입력 가능합니다. (아래 Excel 가져오기 섹션 참고)

방법 B — 직접 입력: "+ 행 추가" 버튼으로 행을 만들고, Product / Primer / Prefix를 입력합니다.
6
"↔ 짝꿍 자동 완성"을 클릭합니다
프라이머는 F/R 짝꿍 쌍이 있습니다. T7-F를 입력했다면 SP6-R 행이 자동으로 추가됩니다. 같은 Product · 같은 Prefix가 적용됩니다. (자세한 내용은 짝꿍 프라이머 섹션 참고)
7
"저장" 버튼을 클릭합니다
규칙이 브라우저에 저장됩니다. 규칙 관리 표에서 등록된 내용을 확인할 수 있습니다.
3
매일 사용하기 — AB1 파일 변환
규칙이 설정된 이후의 일상적인 사용 방법
1
변환할 .ab1 파일을 업로드합니다
"AB1 파일 업로드" 영역에 파일을 드래그하거나, 영역을 클릭하여 파일을 선택합니다.
여러 파일을 한 번에 선택할 수 있습니다. (Ctrl+A 전체 선택 가능)
2
변환 미리보기를 확인합니다
업로드 즉시 아래 표에 변환 결과가 표시됩니다.
✓ 변환됨 — 규칙이 적용되어 새 파일명이 생성됨
✗ 불가 — 해당 파일에 맞는 규칙이 없음 (이유 표시됨)
3
ZIP 다운로드 버튼을 클릭합니다
변환된 파일만 ZIP으로 묶여 저장됩니다.
ZIP 파일명은 첫 번째 파일의 앞 3파트로 자동 결정됩니다.
예: NOTCH3_260507_7370170.zip
⚠
변환 불가 파일이 있는 경우
경고 박스에 해당 ITEM 이름이 표시됩니다. "ITEM 변환 규칙 관리"에서 해당 ITEM의 규칙을 추가하거나, 규칙 테이블에 해당 Product+Primer 조합을 추가한 후 파일을 다시 업로드하세요.
4
Excel에서 규칙 가져오기
기존 접수 파일에서 매핑 규칙을 자동으로 불러옵니다

ITEM 규칙 추가/수정 창 안의 "↑ Excel에서 가져오기" 버튼을 누르면 Excel 파일을 읽어 Product × Primer → Prefix 조합을 자동으로 채워줍니다.

가져오기 창 사용 방법

1
Excel 파일을 선택합니다
파일을 선택하면 열 매핑 창이 열리고, 파일의 첫 6행이 미리보기로 표시됩니다.
2
각 열이 무엇인지 지정합니다
샘플ID/Product 열: 파일명 형식의 샘플 ID가 있는 열 (예: NOTCH3_260507_7370170_M1)
Primer 열: 프라이머명이 있는 열 (예: T7-F)
Prefix 열: 접두어가 있는 열 (예: ex1) — 없으면 "없음" 선택

선택한 열은 미리보기 표에서 색상으로 강조됩니다.
3
하단의 "유효 행: N개"를 확인하고 가져오기를 클릭합니다
0개로 표시되면 열 지정이 잘못된 것입니다. 다시 확인 후 가져오기를 진행하세요.
항목설명예시
시작 행헤더가 없으면 1행부터, 헤더가 있으면 2행부터기본: 1행부터
Product 방식샘플ID에서 추출 (M1이 포함된 전체 ID) 또는 Product 직접 열 (M1만 있는 열)마크로젠 접수 파일 → 샘플ID에서 추출
Prefix 없음접두어 열이 없어도 가져올 수 있음. Product+Primer만 먼저 등록 후 Prefix는 나중에 직접 입력Prefix 열 = 없음 선택
⚠
가져오기는 추가/업데이트만 합니다. 기존에 입력된 행은 삭제되지 않으며, 동일한 Product+Primer 조합이 있으면 Prefix 값만 업데이트됩니다.
5
짝꿍 프라이머 자동완성
F/R 프라이머 쌍을 자동으로 인식하여 규칙을 완성합니다

생거 시퀀싱은 동일한 앰플리콘을 Forward(F)와 Reverse(R) 방향으로 모두 읽는 경우가 많습니다. 두 방향 모두 같은 엑손이므로 같은 Prefix가 적용됩니다.

이 도구는 아래 5쌍을 짝꿍으로 자동 인식합니다.

pMAL-F
↔ 짝꿍
pMAL-R
pQE-F
↔ 짝꿍
pQE-R
T7-F
↔ 짝꿍
SP6-R
T3-F
↔ 짝꿍
T7t-R

짝꿍 표시 및 사용 방법

짝꿍 열 표시의미할 일
✔짝 (초록)같은 Product에 짝꿍 행이 이미 있음없음 (완료)
+ SP6-R (주황 버튼)짝꿍 행이 없어 클릭하면 바로 추가됨버튼 클릭
- (회색)이 프라이머는 5쌍에 포함되지 않음필요 시 직접 입력
💡
↔ 짝꿍 자동 완성 버튼을 한 번만 누르면 테이블 전체를 검사해서 빠진 짝꿍을 모두 한 번에 추가합니다. Excel 가져오기 후 바로 이 버튼을 누르는 것을 권장합니다.
6
Primer 단독 모드 LHON 등 단일 Product 유전자
Product(M1/M2) 없이 Primer만으로 접두어를 결정하는 경우

어떤 경우에 사용하나요?
대부분의 유전자(BRCA1, NOTCH3 등)는 여러 개의 Product(M1, M2…)가 있어 파일명에 Product가 포함됩니다. 그런데 LHON처럼 앰플리콘이 하나뿐인 유전자는 Product 번호가 없이 Primer 이름만 파일명에 포함됩니다.

일반 모드 (Product × Primer)
BRCA1_250924_7500443_M1_SP6-R.ab1
↓ M1 + SP6-R → ex1 적용
BRCA1_250924_7500443_ex1_M1_SP6-R.ab1
Primer 단독 모드
LHON_260207_8102811_pMAL-R.ab1
↓ pMAL-R → ND4 적용
LHON_260207_8102811_ND4_pMAL-R.ab1

두 모드의 차이

항목일반 모드Primer 단독 모드
파일명 구조ITEM_날짜_번호_M1_SP6-R.ab1ITEM_날짜_번호_pMAL-R.ab1
매핑 기준Product + Primer 조합Primer만
삽입 위치(pos)Product가 있는 자리Primer가 있는 자리
접두어 형태ex1, ex2… (엑손 번호)ND1, ND4… (유전자 유형)
매핑 테이블Product 열 + Primer 열Primer 열만 (Product 열 숨김)

LHON 규칙 설정 방법 (단계별)

1
"+ ITEM 규칙 추가"를 클릭합니다
ITEM 이름에 LHON을 입력합니다.
2
매핑 모드에서 "Primer → Prefix (단독)"을 선택합니다
빨간 버튼으로 강조되면 Primer 단독 모드가 활성화됩니다.
매핑 테이블에서 Product 열이 자동으로 숨겨집니다.
3
삽입 위치를 확인합니다
LHON(1)_날짜(2)_샘플번호(3)_pMAL-R(4)에서 Primer가 4번째이므로 → 4 입력
창 하단 미리보기에서 LHON_날짜_번호_ND4_pMAL-R.ab1 형태로 표시되면 정확합니다.
4
Primer → Prefix 매핑을 입력합니다
"+ 행 추가"로 행을 만든 뒤 Primer와 Prefix를 입력합니다. Product 열은 보이지 않으며, 입력하지 않아도 됩니다.

예시:
PrimerPrefix (접두어)
pMAL-FND4
pMAL-RND4
T7-FND1
SP6-RND1
5
"↔ 짝꿍 자동 완성"을 클릭하고 "저장"합니다
짝꿍 자동완성도 Primer 단독 모드에서 정상 동작합니다. pMAL-F를 입력했다면 pMAL-R 행이 자동 추가됩니다.
💡
저장 후 규칙 목록에서 LHON 항목 옆에 "Primer 단독" 노란 배지가 표시되어 다른 규칙과 구분됩니다.
⚠
모드를 잘못 선택한 경우
LHON 파일을 올렸을 때 "매핑 없음 (M1+pMAL-R)" 또는 "파트 수 부족"이 표시되면 규칙 모드가 잘못 설정된 것입니다. 해당 규칙을 수정(✏)하여 모드를 "Primer 단독"으로 변경하세요.
❓
자주 묻는 질문 / 문제해결
파일을 올렸는데 "변환 불가"로 표시됩니다.
표의 "새 파일명" 칸에 이유가 표시됩니다.
• 규칙 없음: 해당 ITEM에 대한 규칙이 없습니다. "ITEM 규칙 관리"에서 해당 유전자 규칙을 추가하세요.
• 매핑 없음 (M3+SP6-R): 규칙 테이블에 해당 Product+Primer 조합이 없습니다. 규칙 수정에서 해당 행을 추가하세요.
• 파트 수 부족: 파일명에 _로 분리된 파트가 Product 위치보다 적습니다. Product 위치 설정을 확인하세요.
컴퓨터를 바꿨더니 BRCA1 말고 다른 규칙이 사라졌어요.
규칙은 해당 브라우저의 localStorage에 저장됩니다. 다른 컴퓨터나 다른 브라우저에서는 다시 설정해야 합니다. 규칙이 많은 경우, 설정 후 Excel 파일로 백업해두는 것을 권장합니다.
Excel 가져오기에서 "유효 행: 0개"가 뜹니다.
열 지정이 잘못되었을 가능성이 높습니다.
• 샘플ID 열: NOTCH3_260507_7370170_M1 형태의 값이 있는 열을 선택했는지 확인
• Primer 열: T7-F, SP6-R 등의 값이 있는 열을 선택했는지 확인

BRCA1 규칙을 실수로 삭제했어요.
브라우저 캐시나 localStorage를 지우거나, BRCA1 규칙을 삭제하면 복구할 방법이 없습니다. 하지만 이 도구에는 BRCA1 기본 규칙이 내장되어 있어, localStorage에 데이터가 전혀 없을 때 자동으로 복원됩니다. localStorage를 초기화하면 기본 규칙으로 돌아옵니다.
5쌍에 없는 프라이머를 사용할 때는 어떻게 하나요?
Primer 드롭다운 맨 아래의 "직접 입력..."을 선택하면 텍스트 입력란이 나타납니다. 프라이머 이름을 직접 입력하면 됩니다. 짝꿍 자동완성은 작동하지 않으므로, 짝꿍 행은 별도로 추가해야 합니다.
LHON처럼 파일명에 Product(M1/M2)가 없는 유전자는 어떻게 규칙을 만드나요?
"Primer 단독 모드"를 사용합니다.
규칙 추가/수정 창에서 "Primer → Prefix (단독)" 버튼을 선택하면 Product 열이 숨겨지고, Primer만으로 접두어를 매핑할 수 있게 됩니다.

예: LHON_260207_8102811_pMAL-R.ab1 → LHON_260207_8102811_ND4_pMAL-R.ab1
자세한 내용은 "Primer 단독 모드" 섹션을 참고하세요.
